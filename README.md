# Rope Buddy downloads

Rope Buddy hangs a little buddy from a rope on your desktop. Pull the rope, let go, and watch it swing.

Get the newest version from the [latest release](https://github.com/aspro-rustler/rope-buddy-releases/releases/latest):

| Computer | File to download |
| --- | --- |
| Windows | `rope-buddy_<version>_x64-setup.exe` |
| Mac with Apple silicon (M1 and later) | `rope-buddy_<version>_aarch64.dmg` |
| Mac with an Intel chip | `rope-buddy_<version>_x64.dmg` |
| Linux | `.AppImage`, `.deb` or `.rpm` |

Once installed, Rope Buddy checks this page for new versions by itself and offers to update.

This repository only holds the release files. The `latest.json` and `.sig` files attached to each release are what the app's updater reads; you don't need to download them.
